# Basemap assets

Fonts (glyph PBFs) and sprites for the built-in OpenStreetMap basemap, from
[protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets).

- `fonts/`: Noto Sans, [SIL Open Font License](fonts/OFL.txt).
- `sprites/v4/dark*`: derived from MIT-licensed
  [tangrams/icons](https://github.com/tangrams/icons/blob/master/LICENSE.md).
